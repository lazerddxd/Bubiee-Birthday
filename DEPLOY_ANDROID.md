# Deploy Gratis dari Android
1. Ekstrak ZIP.
2. Upload isi folder project ke repository GitHub (bukan ZIP sebagai satu file).
3. Root harus memiliki package.json, server.js, dan folder public.
4. Di Render: New > Web Service > pilih repository.
5. Build Command: npm install
6. Start Command: npm start
7. Pilih Free lalu Deploy.
8. Render memberi URL https://....onrender.com
